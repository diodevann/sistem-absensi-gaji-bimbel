# 🏢 Sistem Otomatisasi Absensi & Penggajian Karyawan Bimbel

Ini adalah proyek portofolio aplikasi web cerdas yang saya kembangkan untuk mendigitalisasi proses kehadiran dan perhitungan gaji secara otomatis. 

*(Catatan: Repository ini hanya berisi dokumentasi portofolio. Kode sumber/source code bersifat Private/Rahasia untuk menjaga keamanan sistem dan privasi perusahaan).*

## 🌟 Fitur Utama
* **Validasi Lokasi (GPS):** Karyawan hanya bisa melakukan absensi jika berada di lokasi cabang bimbel.
* **Keamanan Waktu Real-Time:** Mencegah manipulasi waktu absensi oleh pengguna.
* **Integrasi Database Langsung:** Data absensi langsung masuk ke database pusat secara *real-time*.
* **Otomatisasi Penggajian (Backend):** Menghitung gaji berdasarkan jam hadir secara otomatis.
* **Portal Owner & Karyawan:** Antarmuka yang terpisah antara akses admin (pemilik) dan akses pengguna (karyawan).

## 🛠️ Teknologi yang Digunakan
* **Frontend:** HTML5, CSS3, JavaScript (Di-hosting di Netlify)
* **Backend:** Python (Di-hosting di PythonAnywhere)
* **Database:** Supabase (PostgreSQL)
